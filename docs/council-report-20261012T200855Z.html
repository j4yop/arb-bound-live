Council Verdict: the TinyFish Builder Challenge project

5 advisors · 3 anonymous peer reviewers · convened 12 Oct 2026
Complete the challenge compliance package in the first hour — it is the graded artifact. Then build a TinyFish-backed live-data plane for arb-bound, but only after a free, 30-minute gate.

The rubric scores a first successful run, a dashboard screenshot, two social posts and a form — not your code. So the plan is deliberately inverted: bank the package in hour one at zero risk, and make the project contingent and gated rather than load-bearing.

Never make an unverified vendor capability the thing your demo stands on. TinyFish's marketing says its stealth defeats Cloudflare/DataDome. Nobody — including us — has verified it against mcxindia.com, which is Akamai-protected and which we already know returns HTTP 403 to datacenter IPs. That is a hypothesis with a test, not a premise.

Contested points

CONTESTED

Candidate A vs Candidate B

Contrarian + First Principles call A proxy substitution cosplaying as innovation and put Monitor at the core. Expansionist + Outsider say A, reframed around the block, is the maximum leverage.

Resolution: both are right about different things. B is the more durable capability; A is the more legible story. Build A's plumbing, make B its payload, gate both.

CONTESTED

E as floor vs E as waste

First Principles calls minimal compliance empty — it wastes the $8 and teaches nothing. Executor + Contrarian call it insurance.

Resolution: the Executor wins on expected value. E costs 30 minutes and removes all downside; the philosophical objection costs real points if the screenshot never lands.

Blind spots caught in peer review

MISSED BY ALL 5

Optics and terms-of-service exposure

Nobody priced what it means for a sponsor's own judges to hear a pitch about circumventing a regulated exchange's bot defence. The 403 is a great story about the problem and a poor story if framed as the achievement.

MISSED BY ALL 5

Packaging budget

Not one advisor allocated an hour, a capture plan or a narrative to the screenshot, the post copy and the form — the cheapest points on the board, at zero vendor risk. Now it is Phase 0.

MISSED BY ALL 5

Artifact unverifiability

A green fetch test on a bhavcopy proves nothing about the circular archive, which was the thing never reached. Hence four separate gate checks, each with its own pass criterion.

The recommended plan

0

Compliance package — 60 min · zero risk · free

Referral signup → API key → connect to an AI assistant → one real run to completion → dashboard screenshot → follow both X accounts → post on X → post on LinkedIn → submit the form once. This is the graded artifact.

1

The gate — 30–45 min · free

Four checks, all using Fetch rather than Agent so they cost nothing: G1 a live MCX bhavcopy URL; G2 a specific MCX circular PDF; G3 the MCX circular archive listing; G4 an Agent run against the archive returning JSON matching output_schema.

2

Scope to green — 5 min

G1–G4 pass → build the full plane including the Monitor. G1–G2 pass, G3–G4 fail → scope to bhavcopy-only live ingestion plus a Search-based circular lookup. All fail → keep the compliance package and publish the MCX negative result, which is exactly what arb-bound already does when a hypothesis fails.

3

Build — 2–3 h · only if gated green

A thin plane that feeds the unchanged engine. The engineering invariant that makes this safe to attach to a finished project: zero new domain logic, so all 73 existing tests still apply and a web-layer failure degrades the project to exactly what it is today.

4

Package the story — 30 min

Screenshot, an X post, a LinkedIn post, and a README section stating the gate results honestly — including which check failed, if any did. Lead with live data → real engine → real verdict, not "we beat Akamai." MCX is the arena; it is not the pitch.

The immediate next step

Click the official HIH referral link, create the TinyFish account, create the API key, and store it in arb-bound/.env.

That single step unlocks Phase 0, Phase 1 and every decision after it — and it is the only step that cannot be done for you.

Advisors, in their own words

A · The Contrarian / Red Team

Verdict: do E, plus a budget-gated spike. Never let an unverified vendor claim be load-bearing on demo day.

The graded artifact is the first run, the screenshot, the posts and the form. A bets the whole demo on a marketing claim you never validated — if MCX 403s the agent, the demo collapses on the one thing you advertised, and $8 of agent steps burn retrying. B monitors a door you have never opened. C is derivative and fragile. The move: bank E, then run one capped spike.

B · The First Principles Thinker

The premise is a just-so story; only Monitor adds capability.

“Value comes from removing a real constraint. Jay's constraint — MCX 403/Akamai — is real. But TinyFish Fetch/Browser is, mechanically, another read-proxy. He already solved this with r.jina.ai. Swapping proxies is vendor substitution, not new capability.”

TinyFish's differentiated primitives are exactly two: Agent and Monitor. Only Monitor produces signal arb-bound structurally cannot have — temporal data, contract-spec changes over time. The irreducible core is one Monitor wired to circulars, emitting one field into the engine, plus one real first run.

C · The Expansionist / Strategist

A, reframed as a capability proof — claim a position, not a submission.

“What nobody in TinyFish's community has shown is the thing TinyFish's enterprise future depends on: stealth Fetch defeating Akamai-class bot defence on a real, regulated, high-value source. Jay's 403 is not an obstacle — it's the demo.”

TinyFish's own GTM needs this artifact, and it is what they publish “under your name.” Funnel into the Student Program → Bounty Board → Ambassador → accelerator Golden Ticket. The ingestion layer becomes the substrate for B — a data plane, not a one-off. Everyone else is optimising a form submission.

D · The Outsider / Domain Skeptic

The 15-second test: gold arbitrage fails. “The website blocked me” wins.

“Say 'arb-bound' out loud to a stranger. Then GOLDGUINEA / GOLDM / GOLDPETAL / GOLDTEN. They are gone. That is a resume, not a pitch.”

Buried in the dossier is the one thing a stranger instantly gets: the site banned robots. That pain is the product; the arbitrage is the excuse. A is the right raw material, mis-sold. Keep MCX as the arena, not the story.

E · The Executor / Pragmatic Engineer

Ship E as insurance, then gate everything on one Fetch call.

The make-or-break is a 30-minute test, not a project. E: 30 minutes, ~99% reliable, guarantees the challenge is satisfied no matter what. Then the A-gate: use Fetch, not Agent — $8 is only ~500 agent steps. Then build A if green (TTFWD ≈ 2 h, ~70% live-demo probability) else B (≈ 3 h, ~85%).

Failure points named: the bhavcopy is a zip/CSV and not HTML, so Fetch may need to be Browser/Playwright; the circular archive may stay walled; do not fan out agents and blow the budget.
